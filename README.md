# Word to PDF Converter
[![CI Pipeline](https://github.com/mihisara-koralage/word-to-pdf-converter/actions/workflows/ci.yml/badge.svg)](https://github.com/mihisara-koralage/word-to-pdf-converter/actions/workflows/ci.yml)

A simple Node.js Express application that allows users to upload a Word document and download it as a PDF.

## Features

- Upload DOCX files
- Convert DOCX to PDF
- Download generated PDFs
- File validation
- Upload size limits
- Error handling

## Tech Stack

- Node.js
- Express.js
- Multer
- LibreOffice
